# Техническое задание — Голосовой ИИ-ассистент для КТ-протоколов

> Версия: 0.1 — источник контента для конфигов движка. Автор: врач-рентгенолог (НИИ).
> Этот файл — «источник истины» по формулировкам, формулам, порогам и правилам.
> Движок (`server/src/radiology/`) реализует эту спецификацию как data-driven шаблоны.

## Очерёдность внедрения (утверждено врачом)

**Очередь 1 — самые частые и выгодные (делаем сейчас):**
1. КТ ОБП с контрастом ← эталонный шаблон v1
2. КТ ОГК
3. КТ мочевыделительной системы / КТ-урография
4. КТ головного мозга
5. КТ придаточных пазух носа

**Очередь 2 — сложные, но стандартизируемые:** КТА БЦА, КТА сердца, Панаортография, Энтерография, ОМТ.

**Очередь 3 — костно-суставные (низкий приоритет, копипаст и так быстр):** плечевой/коленный/тазобедренный суставы, ШОП, ГОП, ПКОП.

## 1. Общая концепция

Голосовая команда врача → распознавание медицинских сущностей → заполнение
структурированных полей → генерация текста описания → расчёты → контроль
противоречий → формирование заключения.

Врач НЕ диктует весь протокол свободным текстом. Основной режим — короткие команды:

```
ОБП контраст.
Печень плотность 56, норма.
Желчный пузырь камни, стенка 2 мм, воспаления нет.
Селезёнка размеры 14 7 5.
Портальная система норма.
Правая почка Босняк 1, 18 мм.
Жидкости нет. Газа нет.
Заключение автоматически.
```

## 3. Универсальная структура шаблона

### 3.1 Блок техники
- Тип исследования: нативное / с в/в контрастированием / многофазное / ангиография / низкодозовое / энтерография / урография
- Фазы: нативная / артериальная / панкреатическая / портально-венозная / отсроченная / экскреторная
- Качество: диагностическое / ограничено артефактами / дыхательными артефактами / отсутствием контраста / плохой подготовкой

### 3.2 Органные блоки — у каждого:
1. Норма  2. Типовые патологии  3. Измеряемые параметры  4. Классификационные поля
5. Автозаключение  6. Проверка противоречий  7. Команда «не выносить в заключение»

### 3.3 Автозаключение — собирается из клинически значимых находок:
воспаление, опухоль, обструкция, тромбоз, кровотечение, свободный газ, свободная
жидкость, метастазы, портальная гипертензия, ишемия, критические стенозы, патологические переломы.

## 4. Универсальные голосовые команды

| Команда | Действие |
|---|---|
| «ОБП шаблон норма» | Весь протокол ОБП нормой |
| «печень норма» | Только блок печени нормой |
| «удалить последнее» | Отменить последнюю команду |
| «заменить блок печени» | Перезаписать блок печени |
| «добавить в заключение» | Вынести текущую находку в заключение |
| «не выносить в заключение» | Оставить находку только в описании |
| «заключение автоматически» | Собрать заключение по правилам |
| «сравнить с предыдущим» | Активировать блок динамики |
| «без динамики» | Формулировка стабильности |
| «прогрессия» / «регрессия» | Ухудшение / положительная динамика |
| «остальное норма» | Все незаполненные блоки → норма |

## 5. КТ ОБП — разделы
1. Техника  2. Печень  3. Очаговые образования печени  4. Желчные протоки
5. Желчный пузырь / после холецистэктомии  6. Поджелудочная железа  7. Селезёнка
8. Портальная система  9. Желудок и парагастральные лимфоузлы  10. Надпочечники
11. Почки  12. ЧЛС и мочеточники  13. Кишечник  14. Брюшина/жидкость/газ
15. Лимфоузлы  16. Сосуды  17. Кости и мягкие ткани  18. Заключение

## 6. ОБП — техника
Команды: `ОБП натив` · `ОБП контраст` · `ОБП три фазы` · `ОБП артериальная венозная отсроченная` · `ОБП панкреатический протокол` · `ОБП качество хорошее` · `ОБП качество ограничено дыханием`.

Автотекст (пример): «Выполнена КТ органов брюшной полости с внутривенным болюсным
контрастированием, с получением артериальной, портально-венозной и отсроченной фаз.
Качество исследования диагностическое.»

## 7. ОБП — печень
Поля: размеры (обычные/увеличена/уменьшена), контуры (ровные/неровные/бугристые),
структура (однородная/неоднородная), **средняя плотность паренхимы ___ HU (обязательное числовое поле)**,
фаза оценки плотности (нативная/венозная/не оценивалась), очаговые образования (нет/есть),
внутрипечёночные протоки (не расширены/расширены).

Норма: «Печень обычных размеров, контуры ровные, структура паренхимы однородная.
Средняя плотность паренхимы печени на нативных изображениях — ___ HU. Очаговых
образований не выявлено. Внутрипечёночные желчные протоки не расширены.»

Правила:
- «печень норма» без плотности → оставить `___ HU` пустым и подсветить как обязательное.
- плотность <40 HU на нативе → предложить «КТ-признаки жировой инфильтрации печени».
- плотность в венозную фазу → НЕ применять нативные HU-критерии стеатоза.
- «цирроз» + контуры ровные + размеры обычные → подсветить «Проверьте морфологические признаки цирроза».

## 8. Цирроз без ГЦР / LI-RADS
Команда: `печень цирроз без ГЦР`. Правила: без многофазного контраста запрещать
«LR-4/LR-5 не выявлено» → заменять на «Оценка по LI-RADS ограничена отсутствием
многофазного контрастирования». Не из группы риска ГЦР → LI-RADS не применять.

## 9. Очаговые образования печени (каждый очаг — отдельный объект)
Поля очага: тип (киста/гемангиома/ФНГ/ГЦР/метастаз/неопределённый), сегмент I–VIII,
размер, плотность нативно HU, поведение в артериальную/венозную/отсроченную фазы,
количество, динамика, категория LI-RADS.

- **Киста** `печень киста S6 12 мм` → «В S6 печени определяется простая киста диаметром 12 мм: жидкостной плотности, с чёткими ровными контурами, без перегородок, солидного компонента и патологического контрастного усиления.» Заключение: «Простая киста S6 печени.»
- **Гемангиома** `печень гемангиома S7 22 мм` — требует артериальную + венозную/отсроченную фазы, иначе «вероятно соответствующими гемангиоме; оценка ограничена фазностью».
- **ФНГ** `печень ФНГ S4 31 мм` — если нет рубца → «без убедительно визуализируемого центрального рубца»; если washout → конфликт.
- **ГЦР / LI-RADS 5** `печень ГЦР S8 28 мм APHE washout капсула LI-RADS 5` — только при многофазном КТ + группа риска.
- **Гиповаскулярные метастазы** `печень метастазы гиповаскулярные множественные от 6 до 24 мм сегменты 2 4 6 8`.

## 10. Желчные протоки
Норма: «Внутри- и внепечёночные желчные протоки не расширены. Холедох не расширен,
просвет его свободен.» Поля: внутрипечёночные, общий печёночный проток мм, холедох мм,
конкремент, уровень/причина обструкции.
Холедохолитиаз: `холедохолитиаз камень 6 мм холедох 11 мм`.

## 11. Желчный пузырь
Норма: «Желчный пузырь обычных размеров, стенка не утолщена. Рентгенконтрастных
конкрементов в просвете не определяется. Перивезикальная клетчатка не изменена.»
- ЖКБ без холецистита: `желчный камни без воспаления`.
- Острый холецистит: `острый холецистит стенка 5 мм камень шейка перивезикальная жидкость`.
- После холецистэктомии: `желчный удалён` → удалить норму ЖП, ЗАПРЕТИТЬ «желчный пузырь обычных размеров», «в просвете желчного пузыря».

## 12. Поджелудочная железа
Норма, липоматоз (`поджелудочная липоматоз`), хронический панкреатит
(`хронический панкреатит кальцинаты проток 5 мм атрофия`).

## 13. Спец-шаблон: рак ПЖ / резектабельность по NCCN
Локализация, размеры 3D, контакт опухоль-сосуд по шкале 0–5, чек-лист артерий (чревный
ствол, ВБА, ОПА, СПА, ГДА, аорта) и вен (воротная, ВБВ, конфлюенс, селезёночная, НПВ).
Резектабельность — вычисляемое поле: резектабельная / погранично / местнораспространённая /
метастатическая / не определяется. Проверки противоречий (СМА >180° + «резектабельная» = ошибка и т.д.).

## 14. Селезёнка
`селезёнка размеры 14 7 5` → **Селезёночный индекс = длина × ширина × толщина**.
Автотекст: «Селезёнка размерами 14,0 × 7,0 × 5,0 см, селезёночный индекс — 490…»
**Индекс > 480 → в заключение «КТ-признаки спленомегалии».**

## 15. Портальная система (самостоятельный блок)
Поля: воротная вена (проходима/тромбирована, мм), ВБВ мм, селезёночная вена мм,
кавернозная трансформация, вариксы пищевода/желудка, параумбиликальная вена,
спленоренальные коллатерали, асцит.
Портальная гипертензия: `портальная гипертензия воротная 16 ВБВ 14 селезёночная 12 вариксы пищевода желудка асцит малый`.
Проверки: «норма» + вариксы = ошибка; тромбоз → запросить полный/частичный, протяжённость, каверному.

## 16. Желудок и парагастральные лимфоузлы
Норма, поля наполнения/стенки/клетчатки/ЛУ/ГПОД. `ГПОД 35 мм`.

## 17. Надпочечники — washout
Поля: сторона, размер, плотность натив/артериальная/венозная/отсроченная HU, время отсрочки,
абсолютный и относительный washout.
```
Абсолютный washout = (венозная HU − отсроченная HU) / (венозная HU − нативная HU) × 100%
Относительный washout = (венозная HU − отсроченная HU) / венозная HU × 100%
```
- нативная ≤10 HU → «липид-содержащая аденома».
- нативная >10 HU + венозная + отсроченная → считать washout.
- нет нативной → только относительный washout.
- отсрочка не 10–15 мин → подсветить «washout может быть некорректен».

`правый надпочечник аденома 18 мм натив 4` · `левый надпочечник образование 24 мм натив 18 венозная 92 отсрочка 34`

## 18. Почки — Bosniak
`правая почка Босняк 1 18 мм` → «…простая кортикальная киста диаметром 18 мм… Bosniak I.»
Проверки: Bosniak I + (перегородки | солидный компонент | усиление) = ошибка.

## 19. ЧЛС, мочеточники, конкременты
Гидронефроз нет/I/II/III/IV, сторона, уровень обструкции, размер и плотность конкремента.

## 20. Свободная жидкость и свободный газ (обязательный раздел)
Норма: «Свободной жидкости и свободного газа в брюшной полости не определяется.»
Команды: `жидкости нет` · `газа нет` · `асцит малый` · `свободный газ под диафрагмой` · `пневмоперитонеум`.
**Свободный газ → ВСЕГДА в заключение, критическая находка.**

## 21. Лимфатические узлы
Локализация, короткая ось мм, количество, конгломераты, некроз, динамика.

## 22. Сосуды
Аорта диаметр мм, чревный ствол, ВБА, НБА, почечные/подвздошные артерии.

## 34. Контроль противоречий (обязательный модуль)
1. «желчный удалён» + «обычных размеров» → ошибка
2. «портальная норма» + «вариксы» → ошибка
3. «селезёнка не увеличена» + индекс >480 → ошибка
4. Bosniak I + перегородки/солид/усиление → ошибка
5. «газа нет» + «пневмоперитонеум» → ошибка
6. «печень норма» + «цирроз» → ошибка
7. «поджелудочная норма» + «опухоль головки» → ошибка
8. «резектабельная ПЖ» + СМА >180° → ошибка
9. «LI-RADS 5» без многофазного контраста → ошибка
10. «аденома по washout» без отсроченной фазы → ошибка

## 36. MVP этапы
- **Этап 1:** ОБП базовый + патологии + портальная + очаги печени + почки/Bosniak + надпочечники/washout + жидкость/газ + автозаключение.
- **Этап 2:** рак ПЖ/резектабельность, ОГК + узлы + Lung-RADS/Fleischner.
- **Этап 3:** КТА сердца, TAVI, БЦА, панаортография, энтерография, позвоночник, суставы.

## 37. Ключевое требование
Система НЕ ставит диагноз без команды врача. Система: структурирует сказанное,
подставляет утверждённые формулировки, считает индексы/washout, проверяет
противоречия, предлагает автозаключение. **Финальное решение — за врачом.**
